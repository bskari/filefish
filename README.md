# FileFish

FileFish is a binary file dissector, similar to Wireshark. It explains what
each set of bytes in an arbitary file means, and allows you to expand, inspect,
and explain blocks of bytes.

## Description

The left panel shows lines that can be expanded for sections of the file, along
with explanations. The right side shows the hex and ASCII bytes.
